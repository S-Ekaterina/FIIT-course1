# FIIT-course1

PPI (Princípy počítačového inžinierstva) - predmet zameraný na základy počítačového inžinierstva, architektúru počítača a fungovanie hardvéru. Zaoberá sa tým, ako sú počítačové systémy zostavené a ako fungujú ich základné časti, napríklad procesor, pamäť, vstupné a výstupné zariadenia a prepojovacie systémy.

PRPR (Procedurálne programovanie) - predmet je zameraný na základy algoritmizácie a procedurálneho programovania v jazyku C, vrátane práce s funkciami, poľami, ukazovateľmi, štruktúrami a súbormi.
