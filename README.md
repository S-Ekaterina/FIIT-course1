<details>
<summary>:green_circle::sunglasses: OOP (Objektovo-orientované programovanie)</summary>
&nbsp;&nbsp;Predmet je zameraný na objektovo-orientované programovanie, programovací jazyk Java a základy objektovo-orientovanej analýzy a návrhu. Zaoberá sa princípmi ako polymorfizmus, návrhové vzory, práca s používateľským rozhraním a tvorba kvalitného a znovupoužiteľného softvéru.
</details>

<details>
<summary>:yellow_circle::sunglasses: PPI (Princípy počítačového inžinierstva)</summary> 
&nbsp;&nbsp;Predmet zameraný na základy počítačového inžinierstva, architektúru počítača a fungovanie hardvéru. Zaoberá sa tým, ako sú počítačové systémy zostavené a ako fungujú ich základné časti, napríklad procesor, pamäť, vstupné a výstupné zariadenia a prepojovacie systémy.
</details>

<details>

</details>

<details>
<summary>:yellow_circle::sunglasses: TZIV (Teoretické základy informatických vied)</summary>
