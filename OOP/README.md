# OOP


I found this course highly engaging and relatively straightforward. The practical part consisted of working on mini-projects in Java, applying core OOP principles. Unfortunately, I only managed to score 78/100 points because, due to a technical glitch, my 2nd and 6th assignments were archived and submitted as empty folders. Sadly, I couldn't prove later that I had finished everything on time. Despite this setback, I have nothing but positive memories of the course.A particularly memorable part was the "skúška" (the final practical exam). It was my very first time experiencing this format—we had to extend an existing project and write the code from scratch directly in the university lab under a tight time limit. Since I had only ever coded comfortably at home, I was incredibly nervous. However, I ended up feeling super proud of myself because I managed to fulfill almost every single requirement except for one.This course truly helped me understand that OOP is a vital foundation for code structure. As a fun bonus, we explored these concepts using Minecraft as an example, which actually inspired me to try making my own mod someday, knowing the game is entirely built on Java!
