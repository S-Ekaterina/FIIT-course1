# Data Structures and Algorithms

&nbsp;&nbsp;This course was a major turning point in my programming journey. We entered this class right after mastering the syntax and grammar of the C language, which shifted our focus from simply "how to write code" to "how to write efficient code."
  
&nbsp;&nbsp;Every week, we received assignments that had to be submitted to an automated grading platform. This tester checked not only the correctness of our solution but also its execution speed and memory consumption. It was a great challenge because it taught me the most crucial aspect of software engineering: algorithms must be both accurate and highly optimized in terms of Time and Space Complexity.  

&nbsp;&nbsp;The course covers all the essential topics, including Singly and Doubly Linked Lists, Stacks, Queues, Trees (BST, Balanced), Heaps, Graphs, Hash Tables, various Sorting Algorithms, Binary Decision Diagrams (BDD), and Hardware Acceleration.     
&nbsp;&nbsp;Personally, the course started quite smoothly for me, and I felt comfortable with the core data structures at first. However, towards the end, the topics became significantly more advanced and challenging. Despite the late-game difficulty, I pushed through, adapted, and successfully passed the course with a final score of 71/100.  
    
&nbsp;&nbsp;The biggest lesson this experience taught me is that making the code "work" and achieving the correct output is only half the battle. True programming lies in optimizing, handling edge cases, and respecting system resources.
